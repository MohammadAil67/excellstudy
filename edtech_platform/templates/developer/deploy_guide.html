Deployment Steps

How to Deploy Your Agent

1
Register Your Agent on the Portal
Before you can push an image, you must register your agent's metadata on the Developer Portal. This creates the registry entry that your image push will be matched against.
Register an Agent
2
Build Your Docker Image
Build your agent image locally. Make sure your manifest.json is included at the container root and your app listens on port 8080.
# Build your Docker image docker build -t my-math-agent:1.0.0 .
Image must be under 4 GB and must not run as root. Test locally before pushing.
3
Tag & Push to the ExcellStudy Registry
Tag your image using your agent's slug (shown on the portal after registration), then push to the ExcellStudy container registry. Replace YOUR_SLUG and VERSION with the values from your portal registration.
# 1. Authenticate with the registry docker login excellstudy.registry.io # 2. Tag your local image docker tag my-math-agent:1.0.0 \ excellstudy.registry.io/YOUR_SLUG:VERSION # 3. Push docker push excellstudy.registry.io/YOUR_SLUG:VERSION
The tag format must match exactly. Pushing to an unregistered tag will be silently discarded.
4
Monitor the Pipeline
Once your image is pushed, the platform automatically triggers the CI/CD pipeline. You can monitor each stage in real time from your agent's Pipeline Status page. The pipeline runs three checks: Schema Validation, Security Scan, and a Smoke Test.
Go to My Agents
5
🎉 Your Agent is Live!
Once all pipeline stages pass, your agent's status changes from Pending to Live and it becomes visible in the learner marketplace. You'll receive a notification in your portal. Learners can now select and use your agent in their sessions.
Pipeline

What Happens During the Pipeline

After your image is pushed, three automated checks run in sequence. All three must pass for your agent to go live.

Schema Validation
manifest.json checked against platform spec
→
Security Scan
Container image scanned for CVEs
→
Smoke Test
Agent deployed and tested with a real request
→
Live
Agent available in marketplace
Troubleshooting

Common Pipeline Failures

If your pipeline fails, check the rejection reason on the Pipeline Status page. Here are the most common issues:

Error Cause Fix
Schema Mismatch Fields in manifest.json don't match portal registration Re-check input_type, output_types, and name match exactly
CVE Detected Security scanner found a known vulnerability in your base image or dependencies Update your base image to a newer version and pin dependencies
Port Unreachable Container is not listening on port 8080 Ensure your app binds to 0.0.0.0:8080
POST /infer 404 Smoke test could not reach the /infer endpoint Verify your route is POST /infer and returns valid JSON
Image Too Large Image exceeds the 4 GB limit Use a lighter base image, remove model weights from the image and load at runtime
Running as Root Container process runs as UID 0 Add USER nonroot to your Dockerfile
Done!

Your agent is on its way

Once the pipeline passes, your agent is automatically published to the ExcellStudy Marketplace. Learners can browse and add it to their teaching team.
